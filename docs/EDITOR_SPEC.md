# 위젯 편집기 상태·화면 명세

## 목적과 경로

- 기존 OBS 위젯은 `/ex-api/`에서 그대로 동작한다.
- 편집기는 `/ex-api/editor/`에 추가한다.
- 편집기는 `팔로우 적립`과 `업보 타이머` 두 탭을 제공한다.
- 편집 결과는 서버에 저장하지 않고 URL 검색 파라미터로만 표현한다.
- 배색은 유레카 고정 테마(초록 종이 + 주황 형광펜)로 유지한다.

## 정보 구조

| 처리 | 항목 | 이유 |
| --- | --- | --- |
| Keep | 문구, 폼 크기, 전체 글자 크기 | 가장 자주 바꾸는 핵심 설정 |
| Merge | 미리보기와 애니메이션 다시 보기 | 결과 확인 동선 하나로 결합 |
| Reveal on demand | 위치별 글자 크기, 데이터 설정 | 기본 사용에는 불필요한 고급 설정 |
| Keep | 위젯 링크, 복사, 새 창 열기 | OBS 적용의 최종 행동 |
| Delete | 테마색 선택 | 유레카 테마 고정 요구와 충돌 |

## 상태 모델

### 편집 상태

- `draft`: 입력 폼의 현재 유효 설정. 모든 숫자는 위젯과 같은 경계로 제한한다.
  새로고침 주기는 편집하지 않고 위젯 기본값 30초를 사용한다.
- `previewUrl`: iframe 전용 URL. 적립 탭은 `preview=1035`,
  `eventDelta=1`, `refresh=10`을 사용한다.
- 타이머 탭의 `previewUrl`은 `preview=1271`, `eventDelta=1`과 현재 시각에
  가까운 미리보기용 `startAt`, `refresh=30`을 사용한다. `previewSequence`로
  T-60 시작 연출과 종료 30초 연출 중 하나를 선택한다.
- `widgetUrl`: `draft`만 포함한 OBS용 URL. `preview`, `eventDelta`를 절대 포함하지 않는다.
  타이머 탭에서는 `mode=countdown`, `startAt`, `session`을 포함한다.
- `copyState`: `idle | success | error`. 복사 결과를 짧은 상태 문구로 알린다.

### 전이

| 현재 | 이벤트 | 다음 | 결과 |
| --- | --- | --- | --- |
| 편집 가능 | 입력 변경 | 편집 가능 | 설정 정규화 후 iframe과 링크 갱신 |
| 적립 탭 | 애니메이션 다시 보기 | 편집 가능 | 같은 `previewUrl`로 iframe 재로딩 |
| 타이머 탭 | 시작 60초 보기 | 편집 가능 | T-60 카운트인부터 T+5 증가 릴레이까지 재생 |
| 타이머 탭 | 종료 30초 보기 | 편집 가능 | 종료 30초 카운트다운과 마지막 +30초 연장을 재생 |
| 적립 탭 | 업보 타이머 탭 선택 | 타이머 편집 | 모든 상태 문구·시작시각·세션과 릴레이 미리보기 표시 |
| 타이머 탭 | 팔로우 적립 탭 선택 | 적립 편집 | 기존 적립 문구와 미리보기 복원 |
| `idle` | 링크 복사 성공 | `success` | “복사됨” 표시 후 `idle` 복귀 |
| `idle` | 링크 복사 실패 | `error` | 직접 선택 안내 후 `idle` 복귀 |

## 불변 조건

- 루트 위젯의 기존 URL 파라미터는 계속 지원한다.
- 사용자 문구는 `textContent`로만 출력하고 길이를 제한한다.
- 미리보기용 데이터와 10초 갱신 설정은 실제 OBS 링크에 포함하지 않는다.
- 편집기는 API 비밀값을 받거나 저장하지 않는다.
- 650×100, 기준 1,031명, 팔로워당 30초가 기본값이다.

## 모션

- iframe 갱신은 입력 중 과도한 재로딩을 막기 위해 짧게 지연한다.
- 적립 탭의 “다시 보기”는 팔로워 1명 증가와 `+30초` 이벤트를 재생한다.
- 타이머 탭은 “시작 60초 보기”와 “종료 30초 보기”를 별도 버튼으로 제공한다.
- 버튼과 상태 전환은 120~220ms 범위로 사용한다.
- `prefers-reduced-motion`에서는 이동과 확대를 제거한다.

## 완료 조건

- 문구·가로·세로·전체 글자 크기가 미리보기에 즉시 반영된다.
- 위치별 글자 크기를 독립적으로 조절할 수 있다.
- 생성 링크를 복사하고 새 창에서 열 수 있다.
- `npm test`, `npm run lint`, `npm run build`를 통과한다.
- 데스크톱·태블릿·모바일 폭과 reduced-motion을 실제 브라우저에서 확인한다.
