# 운동 타이머 상태·연출 명세

## 계산 기준

- `mode=countdown`에서만 카운트다운 UI를 사용한다.
- `startAt`은 Unix timestamp 초 또는 밀리초이며, 편집기는 한국시간
  `datetime-local` 입력을 Unix 초로 변환한다.
- 누적 운동시간은 `(최고 팔로워 - 기준 팔로워) × 1명당 적립시간`이다.
- 예상 종료시각은 `startAt + 누적 운동시간`, 남은시간은
  `max(예상 종료시각 - 현재시각, 0)`이다.
- 브라우저가 비활성화되거나 다시 로드돼도 절대시각으로 남은시간을 복구한다.
- `session`과 `startAt`이 같은 게임은 브라우저 저장소의 최고 팔로워와
  종료 상태를 이어 쓴다. 미리보기는 저장소를 사용하지 않는다.

## 650×100 배치

```text
┌──────────────────────────────────────────────────────────────┐
│ 지금 팔로워 1,271 │ 팔로우 누르면 링피트 +30초        [+30초] │
│ 기준 1,031명부터  │ 운동 2시간              이대로면 23:30:00 │
└──────────────────────────────────────────────────────────────┘
```

- 기존 약 174px 팔로워 구역과 외곽 폼을 그대로 사용한다.
- 오른쪽 아래의 남은시간은 주 정보이며, 종료시각은 약 105px 보조 블록이다.
- `운동` 라벨만 시간보다 작게 표시해 `1시간 59분 30초`와 종료시각이
  650px 안에서 함께 보이게 한다.
- 자정을 넘는 종료시각은 `8.3. 00:00:30`처럼 날짜를 붙인다.

## 상태

| 상태 | 표시 |
| --- | --- |
| `waiting` | `T < -60초`: 결과 라벨은 `적립`, 상단은 통상 행동 문구만 표시하고 적립시간 뒤 주황 배경은 유지 |
| `count-in` | `T-60초 ~ T-1초`: 상단은 `준비중 >> 링피트`, 하단은 `-60초`부터 매초 주황색으로 다시 표시 |
| `starting` | `T=0 ~ T+2초`: 상단은 통상 행동 문구로 복귀하고 `링피트 시작!!` 문구와 배경을 3초간 그대로 유지 |
| `running` | `T+3초`부터 남은시간을 주황 배경 위에서 1초씩 감소, 종료시각은 고정 |
| `gain` | 추가량, 남은시간, 종료시각을 릴레이로 갱신 |
| `ending` | 남은 30초부터 남은시간 전체를 주황색으로 매초 다시 표시 |
| `final-check` | 0초에서 최종 팔로워 응답과 최소 3초를 함께 기다림 |
| `ended` | 추가 팔로워가 없을 때 `팔로워 구역 | !!! 링피트 완주 !!! | 종료시간 구역`으로 가운데 정렬 |

시작 전에도 `startAt` 기준의 정각 초 경계에 맞춰 다시 렌더링하므로,
OBS를 어느 시점에 불러와도 카운트인 문구가 최대 1초 늦게 바뀌지 않는다.
T=0 이후 결과 라벨은 `적립`에서 `운동`으로 전환된다.
정상 진행 중에는 남은시간 뒤의 주황 배경을 계속 유지한다. 팔로워 증가로
남은시간이 늘어날 때에만 같은 배경을 왼쪽에서 오른쪽으로 다시 그어
시간 추가가 반영됐음을 보여준다.

## 팔로워 조회 시각

- 일반 조회는 `startAt` 기준 30초 격자에 맞춘다.
- 시작 연출 중 확인한 증가는 바로 연출하지 않고 첫 정상 타이머가 나타난 뒤
  `T+5초` 조회에서 합쳐 보여준다.
- 이후 일반 조회는 `T+30초`, `T+60초`처럼 다시 30초 격자를 따른다.
- 종료 30초 안에서는 남은 `30·20·10·5·1·0초`에 별도로 조회한다.
- 0초에서는 마지막 응답이 돌아오고 3초 유예가 지난 뒤에만 종료한다.
- 남은 5초 이하에서 시간이 추가되면 릴레이 동안 상단을 `끝난줄?`로 바꾼다.

## 팔로우 증가 릴레이

전체 노출은 기존 증가 티켓과 같은 약 2.15초다.

1. `0~150ms`: `+30초` 티켓이 오른쪽에서 진입한다.
2. `120~480ms`: 티켓에서 남은시간으로 주황 속도선이 내려간다.
3. `230~710ms`: 늘어난 남은시간이 위로 착지하고 전체 주황선이 그어진다.
4. `510~870ms`: 주황 대시가 종료시각으로 이동한다.
5. `580~1060ms`: 종료시각 숫자가 오른쪽으로 밀리며 새 값으로 교체된다.
6. `1500~1820ms`: 시간 주황선과 종료시각 밑줄을 오른쪽으로 접는다.
7. `1860ms`: 절대시각 기준 남은시간으로 다시 동기화한다.

평상시 감소 숫자는 아래 방향, 적립된 시간은 위 방향, 늦춰진 종료시각은
오른쪽 방향으로 움직인다. 세 방향은 각각 감소·추가·지연의 의미를 갖는다.

## 미리보기

편집기 타이머 탭에는 독립된 두 미리보기가 있다.

- `시작 60초 보기`: `T-60초`부터 카운트인을 재생하고, 시작 문구가 사라진
  `T+5초`에 대기 중인 팔로워 1명 증가를 `+30초` 릴레이로 보여준다.
- `종료 30초 보기`: 남은 30초부터 매초 주황 배경을 다시 그리고, 0초 최종
  확인 중 팔로워 1명이 늘어 `끝난줄? → +30초 연장`으로 이어지는 장면을
  재생한다.

두 샘플 모두 시작시각을 현재 분의 `:00`으로 맞추므로 종료시각의 초는
팔로워가 늘 때마다 `:30 → :00` 또는 `:00 → :30`으로만 이동한다.

```text
운동 1시간 59분 30초 → 운동 2시간
예상 종료시각 → 30초 뒤
```
